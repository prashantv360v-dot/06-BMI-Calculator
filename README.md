# BMI Calculator 

A simple and responsive Body Mass Index (BMI) calculator build using **HTML5**, **CSS**, and **JAVASCRIPT**.
This web application allows users to easily calculate their BMI entering their height (in cm) and weight (in kg) and instantly views their health category.

## Features
- Cleam and user-friendly interface.
- Calculates BMI accurately using metric units (cm and kg).
- Validates user input to prevent errors (e.g.,negative numbers or empty fields).
- Categorizes the result into:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese

 ## Technolgies Used
 - **HTML5** : Structure of the wed page.
 - **CSS3** : Styling and layout design.
 - **JAVASCRIPT** : Core logic for BMI calculation and dynamic result rendering.
